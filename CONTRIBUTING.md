# Contributing

1. Branch from `main` using a prefix: `feat/`, `fix/`, `refactor/`, `chore/`, `docs/`.
2. Keep PRs focused — one logical change per PR.
3. Add or update tests for any behaviour change.
4. Make sure `npm run typecheck` and `npm test` pass locally.
5. Fill in the PR description: **what**, **why**, and **how it was tested**.
